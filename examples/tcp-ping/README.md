# tcp-ping：节点外部指标示例（Go）

定时从插件所在的机器，TCP 连接每个节点第一个启用的入站端口，把结果上报为节点的**外部指标**：

| 指标 | 单位 | 说明 |
| --- | --- | --- |
| `tcp.latency` | `ms` | 连接成功时的 TCP 握手耗时 |
| `tcp.reachable` | `bool` | 1 = 连得上，0 = 连不上 |

面板在节点详情的「外部指标」卡片里显示它们，并标明来源插件。外部指标不会影响节点的在线状态、心跳或流量。

```bash
PORT=9300 go run .
# 面板：扩展 → 插件 → 安装插件 → http://127.0.0.1:9300
# 安装时批准 nodes:read 和 nodes:metrics:write
```

设置（插件页可改）：

- **探测点名称**：写在指标显示名前，例如部署在上海电信机房就填「上海电信」；
- **间隔（秒）**：默认 60，最少 30。

要点：

- 只申请两个权限：`nodes:read` 用来列节点和入站端口，`nodes:metrics:write` 只能写指标，不能改节点。
- 上报前用 SDK 的 `CheckMetric` 自查，避免整批请求被面板拒绝（一次请求里有一个不合规，整批都不保存）。
- 需要面板 0.1.149 及以上（含外部指标接口）。

协议细节见 [docs/subscription.md](../../docs/subscription.md#上报节点外部指标)。
