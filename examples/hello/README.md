# Hello 示例插件

零依赖的 Node.js 参考插件，覆盖协议的每个部分：清单、安装握手、配置推送、健康检查、事件验签与去重、后台页面（`scope=admin` 身份令牌）、用户中心「续期」入口（`scope=user` + `Idempotency-Key`）。

```bash
PORT=9100 node server.js          # 可选：INSTALL_KEY=xxxx 要求安装码
```

面板「扩展 → 插件 → 安装插件」填 `http://127.0.0.1:9100`。凭据保存在 `state.json`（已在 `.gitignore` 中），**真实部署请放到有权限控制的目录**。

这是示例：没有会话管理（每次请求都靠 URL 里的令牌）、没有持久化订单账本。写支付类插件请参考[文档](../../docs)中「幂等」和「身份令牌」的说明。
